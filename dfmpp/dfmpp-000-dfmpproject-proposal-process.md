# DFMPP-000 DFMProject proposal process 0.00v

This paper has not been written yet. It should specify how a project is proposed through DFM, from an issue to adoption.

Until it exists, project proposals follow the same public Git flow as every other contribution, described in the [DFMPProject README](../README.md): a proposal is discussed in a public issue, developed on its own branch and submitted by pull request to `master`.

Writing this paper is open work. Open an issue with the draft. No permission is needed.
